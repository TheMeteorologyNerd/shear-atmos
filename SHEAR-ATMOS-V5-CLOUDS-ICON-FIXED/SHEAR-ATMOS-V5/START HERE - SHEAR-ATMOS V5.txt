SHEAR-ATMOS V5 - EASY START

1. Keep this whole folder together after unzipping it.
2. Double-click: INSTALL SHEAR-ATMOS V5.cmd
3. Wait a moment. SHEAR-ATMOS V5 will open automatically.
4. A new "SHEAR-ATMOS V5" icon is now on your Desktop. Use that icon from now on.
5. In the app, choose "Use my location" when Windows/Edge asks. The forecast, city/state, NWS time, warning tools, and nearest-radar products will then load.

You only need to run the installer once.

If Windows asks whether to allow location, choose Allow. If the app says it cannot load data, check that you are connected to the internet and open the app again from your Desktop icon.

Important: This is a situational-awareness tool. Use official NWS warnings and local emergency instructions for safety decisions.
